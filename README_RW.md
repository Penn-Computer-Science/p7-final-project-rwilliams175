This program runs a secure login window. The goal here is to demonstrate the knowledge gained in our cybsecurity unit mainly, while taking elements from our Tkinter unit. It uses a JSON file, so everything is stored even after the program finishes running. You can create an account, verify the password, login, etc. I did not create a master password as that felt like the opposite of what cybersecurity is focusedd on (creating less threat surfaces). I included hashing basically in the exact same manner we did in our password manager.
